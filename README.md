# ابزار ساخت پروفایل پیکربندی شبکه iOS

این ابزار جهت تولید فایل‌های پیکربندی با پسوند mobileconfig. برای سیستم‌عامل iOS ساخته شده است. نسخه جدید پروژه برای افزایش سازگاری با آیفون ۱۴ و مدل‌های جدیدتر (سری ۱۴، ۱۵ و بالاتر) بهینه‌سازی شده است.

---

## ویژگی‌های اصلی

- پشتیبانی کامل از مدل‌های جدید آیفون (iOS 16 و جدیدتر)
- سازگاری با پروتکل‌های شبکه ۵G و LTE
- اصلاح تنظیمات XLAT464 جهت ارسال بهتر بسته‌های داده
- فرمت استاندارد خروجی به صورت mobileconfig. جهت نصب مستقیم روی دستگاه
- رابط کاربری بهینه‌سازی شده و واکنش‌گرا (Responsive)

---

## دستورالعمل ساخت و نصب پروفایل

### مرحله ۱: ساخت فایل در مرورگر Safari
برای نصب موفق پروفایل‌های iOS، حتماً مراحل را درون مرورگر Safari اجرا کنید.
1. اپراتور سیم‌کارت خود را از لیست کشویی انتخاب کنید.
2. روی دکمه دریافت فایل کلیک کنید.
3. در صورت مشاهده پیغام Allow برای دریافت فایل پیکربندی، گزینه Allow را انتخاب کنید.

### مرحله ۲: نصب پروفایل روی دستگاه
1. وارد برنامه تنظیمات (Settings) دستگاه شوید.
2. گزینه Profile Downloaded در بالای صفحه اصلی تنظیمات را انتخاب کنید.
3. در صفحه باز شده، روی گزینه Install در گوشه بالا سمت راست کلیک کنید.
4. رمز عبور دستگاه (Passcode) را وارد کنید.
5. دکمه Install را مجدداً تایید کنید.

### مرحله ۳: تثبیت تنظیمات
1. یک‌بار حالت هواپیما (Airplane Mode) را روشن کرده و پس از ۵ ثانیه خاموش کنید.
2. در صورت نیاز دستگاه را یک‌بار خاموش و روشن کنید.

## راهنمای حذف پروفایل

در صورت عدم نیاز به پروفایل نصب شده:
1. به مسیر Settings > General > VPN & Device Management بروید.
2. پروفایل مورد نظر را انتخاب کنید.
3. روی گزینه Remove Profile کلیک کرده و رمز دستگاه را وارد کنید.
