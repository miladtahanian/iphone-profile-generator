مولد پروفایل شبکه آیفون ۱۴ به بالا

پشتیبانی
دستورالعمل نصب در iOS:
  1. پس از دانلود، به مسیر Settings دستگاه بروید.
  2. گزینه Profile Downloaded را در بالای صفحه انتخاب کنید.
  3. روی Install کلیک کرده و Passcode دستگاه را وارد نمایید.
  4. یک‌بار حالت هواپیما (Airplane Mode) را فعال و غیرفعال کنید.
دستورالعمل ایجاد Shortcut سوئیچ سریع شبکه:

برای بازنشانی سریع آنتن روی آیفون‌های نسل جدید بدون نیاز به ریستارت، می‌توانید یک Shortcut هوشمند بسازید:

  1. برنامه Shortcuts را در آیفون باز کنید.
  2. روی علامت + در بالای صفحه کلیک کنید تا یک شورت‌کات جدید ایجاد شود.
  3. از بخش افزودن اکشن‌ها (Add Action)، دستور Set Airplane Mode را جستجو و اضافه کنید (مقدار را روی Turn On بگذارید).
  4. دستور Wait را اضافه کرده و زمان آن را روی ۳ ثانیه قرار دهید.
  5. مجدداً دستور Set Airplane Mode را اضافه کنید (مقدار را روی Turn Off بگذارید).
  6. در نهایت دستور Set Cellular Data را اضافه کرده و روی Turn On تنظیم کنید.
  7. نام شورت‌کات را به Reset Network تغییر داده و آن را به صفحه اصلی (Home Screen) یا ویجت‌ها اضافه کنید.
کاربرد Shortcut:

در صورت افت سیگنال یا تغییر دکل شبکه در آیفون‌های ۱۴ به بالا، اجرای این شورت‌کات با یک کلیک ارتباط داده شما را بازنشانی می‌کند.

توسعه یافته برای افزایش سازگاری مودم‌های ۵G و پشتیبانی از XLAT464 روی iOS 16 و بالاتر
